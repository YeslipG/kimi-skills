# 工矿机械产品买卖合同生成 Skill

## 功能说明
根据买方/卖方信息、产品参数，自动生成标准格式的《工矿机械产品买卖合同》Word文档。

**核心规则**：产品种类 **少于3个** 时，自动启用**自适应紧凑排版**，确保合同在**一页A4纸内**完整显示，既不留大量空白，也不溢出到第二页。

## 触发条件

当用户请求以下任务时触发此技能：
- 生成买卖合同/销售合同
- 制作工矿机械产品买卖合同
- 根据买方和产品信息生成合同
- 生成合同Word文档
- 配件销售合同生成

## 输入信息
支持通过**文字、图片、PDF、其他格式文件**提供以下信息：

| 参数 | 必填 | 说明 |
|------|------|------|
| `buyer_name` | ✅ | 买方全称 |
| `product_name` | ✅ | 产品名称 |
| `product_model` | ✅ | 型号规格 |
| `unit` | ✅ | 单位 |
| `quantity` | ✅ | 数量 |
| `unit_price` | ✅ | 单价 |
| `delivery_time` | ✅ | 交货时间 |
| `seller_name` | ❌ | 卖方名称，默认`南通厚普机械科技有限公司`，可选`北京国华技术有限公司` |
| `contract_prefix` | ❌ | 合同编号前缀，默认`HP` |
| `buyer_tax` | ❌ | 买方税号（有则填） |
| `buyer_address` | ❌ | 买方地址（有则填） |
| `buyer_phone` | ❌ | 买方电话（有则填） |
| `buyer_bank` | ❌ | 买方开户行（有则填） |
| `buyer_account` | ❌ | 买方账号（有则填） |

## 输出规则
- **日期**：自动获取当天年月日（如 `2026-06-10`）
- **合同编号**：`{前缀}{年月日}` → `HP20260610`
- **文件名**：`{年月日}-配件销售-合同-{买方简称}-{总金额}`
  - 买方简称：去掉省市名（河北、邢台、天津等）和"有限公司"
  - 示例：`20260610-配件销售-合同-斯塔克传动技术-7200`
- **格式**：`.docx` Word文档，可直接打印

## 排版规则（严格1页内）

产品种类 **< 3个** 时，采用以下精确排版参数：

| 项目 | 参数 |
|------|------|
| 页面 | A4 |
| 上页边距 | 2.0cm |
| 下页边距 | 2.0cm |
| 左页边距 | 3.0cm |
| 右页边距 | 3.0cm |
| 正文字号 | 10.5pt |
| 标题字号 | 20pt，居中 |
| 条款行距 | **18pt（固定值）**，段后0 |
| 产品表格行高 | 0.6cm（340twips，固定值） |
| 双方信息表行高 | 0.6cm（340twips，固定值） |
| 信息行表格行高 | 0.49cm（280twips，固定值） |
| 表格单元格内边距 | **上下0，左右55twips**（消除默认内边距浪费的空间） |
| 信息行对齐 | **左侧**出卖方/买受方，**右侧**合同编号/签订地点/签订时间 |

## 使用示例

### 方式1：直接文字输入
```
买方：斯塔克传动技术（天津）有限公司
卖方：南通厚普机械科技有限公司（默认）
产品：气囊，型号QN9649004，8个，单价900元
交货时间：30天具备发货条件
买方税号：911201025783048440
买方地址：天津市河东区大桥道52号第A座第二层第A225单元
买方电话：13389901520
买方开户行：中国银行天津河西支行
买方账号：272664079711
```

### 方式2：从PDF/图片提取
上传PDF或图片后，AI自动提取买方名称、产品信息、税号、银行账号等，自动填充生成合同。

### 方式3：调用脚本
```bash
python Skills/contract-generator/generate_contract.py
```

或作为模块导入：
```python
from Skills.contract-generator.generate_contract import generate_contract

filepath, filename, contract_no, total = generate_contract(
    buyer_name='斯塔克传动技术（天津）有限公司',
    product_name='气囊',
    product_model='QN9649004',
    unit='个',
    quantity=8,
    unit_price=900,
    delivery_time='30天具备发货条件',
    buyer_tax='911201025783048440',
    buyer_address='天津市河东区大桥道52号第A座第二层第A225单元',
    buyer_phone='13389901520',
    buyer_bank='中国银行天津河西支行',
    buyer_account='272664079711'
)
```
