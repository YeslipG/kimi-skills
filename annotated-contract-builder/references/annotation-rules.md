# 三色标注判定细则

标注的目的是**留痕**：审合同的人只看颜色，就能知道每段内容的来源和处置方式。
判定失准会破坏信任，所以拿不准时回到定义本身。

## 定义

- **灰**：内容来自模板——原样照抄，或在模板字句基础上改写（换名、换数、换日期、适配性措辞）。
- **蓝**：内容来自说明材料——材料里就是这么写的，照抄进合同替换了模板的对应部分。
- **绿**：内容来自说明材料，但进合同时被改动了——适配、补全、纠错、重排。

一句话：**灰看模板，蓝看材料，绿=材料+改动。**

## 判定实例（来自黑龙江伊品安装合同）

### 判灰

| 内容 | 理由 |
|------|------|
| `工程地点：黑龙江伊品生物科技有限公司` | 模板该行改写（用户指定） |
| `总价款为人民币：240000.00元（大写：贰拾肆万元整）` | 模板金额行换数（用户指定） |
| `签约时间：2026年07月20日` | 模板日期行换数（用户指定"今天"） |
| `同时满足黑龙江伊品公司对焊接及喷漆质量等具体要求` | 模板原句"宁夏伊品"的地名适配改写 |
| 第二条安全条款、第八条违约责任 | 模板原文未动 |
| 封面、签署栏 | 模板版式的内容更新 |
| 各级"第X条"标题 | 模板条款框架 |

### 判蓝

| 内容 | 理由 |
|------|------|
| 设备安装 9 项清单（重量、焊缝、板厚） | 材料原文 |
| 6.2.1–6.2.14 乙方权利义务各条（除改动处） | 材料原文 |
| 7.1–7.13 质量保证各条、标准规范清单 | 材料原文 |
| 粉尘防爆/防护装置/噪音/作业要求各细则 | 材料原文 |
| 材料中的设备图、平台图 | 材料原图嵌入 |

### 判绿

| 内容 | 材料原文 | 改动类型 |
|------|----------|----------|
| `包括以下9项设备：` | `包括7部分：`（实列9项，数量矛盾） | 纠错 |
| `乙方进厂施工需遵守甲方…` | `投标方进厂施工需遵守招标方…` | 语境适配（投标语境→合同语境） |
| `…按时调试，确保合` + `同工期。` | 原文残句止于"确保合" | 补全（补的部分标绿） |
| `乙炔` | `乙烘` | 笔误修正（单词标绿，其余蓝） |
| `出入口` | `出人口` | 笔误修正 |
| `10min` | `l0min`（字母l误作数字1） | 笔误修正 |
| `6.2.12.遵守甲方出入检查管理制度…等各项甲方有关规章制度。` | `出入检査``等合格甲方` | 笔误较多，整句标绿 |
| `5.6、吊装作业要求` / `5.7、夜间作业要求` | 原文编号错位：`5.5.4、吊装作业要求` | 重排编号（标题标绿，条内容仍蓝） |

## 粒度规则

- 改动是**个别词**：该词标绿，句子其余部分保持蓝（如 乙炔、出入口、10min）。
- 改动是**整句措辞**：整句标绿（如 投标方→乙方的适配句）。
- 改动是**新增的一句话/小标题**：整体标绿。
- 段落从材料**跨段合并**但文字未动：仍标蓝（不算改写）。

## 易错点

- 用户指定的改动（金额、地点、日期、换甲乙方）是**模板行的改写**→灰，不是绿。绿只用于"材料内容的改写"。
- 标题颜色跟随其内容来源：材料的分节标题（如 `1、设备安装`）→蓝；材料里没有、为成合同而新拟的标题→绿；模板条款标题→灰。
- **标题精简/改名不改变颜色归属**：一级标题按规范压缩字数（如"第二条、工程设备及材料进厂后……"→"第二条、安装准备"）属于格式整理，不是内容改写，颜色保持原归属（模板条款→灰）。
- 图例（标注说明）本身三色各写一句，是最直观的样品，别漏。
