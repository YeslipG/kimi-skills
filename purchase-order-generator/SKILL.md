# 采购单生成器

## 工作流程

### 1. 解析用户输入
- **识别图片内容**：提取截图中的物料信息（序号、物料编码、配件类型、配件名称、规格型号）
- **提取配件类型**：从图片中识别物料的配件类型（如"气动原件"、"电气元件"等），用于文件名
- **解析数量信息**：根据用户提供的数量描述（如"1号20个，2号8个..."）匹配到对应序号
- **生成订单编号**：格式为 PO+日期（如 PO20260320），显示在文档内

### 2. 文档格式规范

#### 页面设置
- 纸张：A4纵向
- 页边距：上下2cm，左右2.5cm
- 默认字体：宋体/微软雅黑

#### 标题
- 内容：**采购单**
- 字体：微软雅黑，18pt，加粗，居中
- 下方空一行

#### 信息区（无框线表格，2行2列）
```
订单编号：PO[日期数字]    日期：[当前日期]
供应商：[用户填写/留空]  需求日期：[用户填写/留空]
```
- 表格无边框
- 第一行内容加粗，第二行正常
- 右列（日期、需求日期）左对齐，确保"日期:"与"需求日期:"垂直对齐
- 列宽：每列约8cm

#### 物料明细表（有框线表格）
**列结构（7列）：**
| 序号 | 物料编码 | 配件类型 | 配件名称 | 规格型号 | 单位 | 数量 |

**样式要求：**
- 表头：灰色底（#F2F2F2），微软雅黑，10.5pt，加粗，居中
- 数据行：宋体，10.5pt，居中
- 列宽：
  - 序号：1.2cm
  - 物料编码：2.2cm
  - 配件类型：2.2cm
  - 配件名称：2cm
  - 规格型号：3.5cm
  - 单位：1.2cm
  - 数量：1.5cm
- 单位列默认填"个"

**合计行（最后一行）：**
- 第一列："合计"（微软雅黑，加粗，居中）
- 中间列：留空
- 最后一列（数量）：总数量（加粗，居中）
- 不合并单元格

#### 备注栏
- 内容：备注：[用户输入/留空]
- 字体：宋体，10.5pt
- 上方空一行

### 3. 输出要求
- 生成标准的.docx Word文档
- **文件名格式**：`[日期][配件类型]PO.docx`
  - 日期格式：YYYYMMDD（如20260320）
  - 配件类型：从截图中提取的主要类型（如"气动原件"、"轴承"、"密封件"等）
  - 示例：`20260320气动原件PO.docx`
- 内容简洁，无表格以外的冗余信息
- 不添加页眉页脚

### 4. 处理逻辑
1. **识别图片**：提取序号、物料编码、配件类型、配件名称、规格型号
2. **提取配件类型**：取第一行物料的配件类型作为文件名组成部分（假设同单同类）
3. **匹配数量**：根据用户提供的数量信息匹配到对应序号
4. **生成编号**：订单编号显示为 PO+日期（如 PO20260320）
5. **计算合计**：自动计算总数量
6. **生成文档**：按上述格式生成Word文件

## 示例

**用户输入：**
- 图片：显示5行物料（配件类型均为"气动原件"）
- 数量："1号20个，2号8个，3号20个，4号20个，5号8个"

**输出文档：**
- 文件名：`20260320气动原件PO.docx`
- 文档内订单编号：PO20260320
- 表格：5行数据 + 1行合计（76）
