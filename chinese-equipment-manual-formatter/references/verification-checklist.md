# Verification checklist

Complete all applicable checks before delivery.

## Package integrity

- [ ] The final `.docx` opens without a repair warning.
- [ ] Section count and section order are intentional.
- [ ] Source and output have the same substantive text, tables, and media, except for approved numbering/TOC/header/footer changes.
- [ ] Image/media count and hashes are unchanged unless an image edit was requested.
- [ ] No tracked changes or comments were accidentally introduced.

## Structure and typography

- [ ] Heading levels are correctly identified.
- [ ] Level 1 headings use Chinese numerals plus `、`.
- [ ] Level 2 headings use `1.` style.
- [ ] Level 3 and 4 hierarchy is continuous and correct.
- [ ] Lists use `1)` style where appropriate.
- [ ] Patent numbers, device models, dates, parameters, and claim numbering were not misclassified.
- [ ] Chinese heading/body fonts and Western fonts match the standard.
- [ ] Heading sizes, boldness, and spacing match the standard.

## TOC and pagination

- [ ] TOC covers heading levels 1–3 and was fully updated.
- [ ] No unintended blank page occurs after the TOC.
- [ ] Cover and TOC show no visible header or page number.
- [ ] Body page numbering restarts at 1.
- [ ] First body page shows `第1页/共Y页`.
- [ ] Last body page shows `第Y页/共Y页`.
- [ ] Footer uses `PAGE` and `SECTIONPAGES`, not a typed number or `NUMPAGES`.

## Header and tables

- [ ] Body header uses the complete cover title and excludes the company name.
- [ ] A short vertical decorative line is visible at the left of the header title.
- [ ] Header and footer do not overlap body content.
- [ ] Table text is left aligned and vertically centered.
- [ ] Every data-table first row is bold with gray fill.
- [ ] Top and left cell margins are 0.2 cm.
- [ ] No table extends beyond the page or clips text.

## Visual inspection

Render or export the final document and inspect at least:

- [ ] Cover page.
- [ ] TOC page(s).
- [ ] First body page.
- [ ] At least two representative middle pages.
- [ ] Every page containing a complex table or large image.
- [ ] Last page.

Check for blank pages, image shifts, clipped content, widows/orphans, isolated headings, unexpected font substitutions, incorrect fields, and inconsistent header/footer variants.

## Final artifact

- [ ] Final filename follows `[原文件名]_按规则排版.docx` unless overridden.
- [ ] The delivered file hash matches the verified working copy.
- [ ] Temporary files and helper scripts are not delivered as the final artifact.
